## 1. 顶栏（App.tsx）—— 所有视图共享

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 文件  编辑  视图  帮助            🏠 任务   📁 工作区   ⚙️ 设置        ─ □ ✕ │ ← h-10 隐藏标题栏
└────────────────────────────────────────────────────────────────────────────┘
   ↑ MenuBar（no-drag）                     ↑ 导航三按钮（no-drag）   ↑ titleBarOverlay
   整条 -webkit-app-region:drag（可拖拽窗口）   激活项 bg-primary          （非UI元素）
```

- **文件**：打开文件夹…｜打开工作目录｜──｜退出
- **编辑**：撤销/重做/剪切/复制/粘贴/全选（execCommand 作用于焦点）
- **视图**：刷新（appReload）｜开发者工具（仅 dev）
- **帮助**（2026-09 新增）：
  - **支持开发者** → 弹窗展示本地「收款码」目录里的收款码图片；
  - **打开官网** → 系统浏览器打开官网 `https://www.lcode.ai.info`。
- **导航逻辑**：在任务详情点"任务"→回列表；在设置页有 activeTaskId → 回任务详情；其他 → 任务列表

**帮助菜单两个入口的实现要点（安全 + 打包）**：
```
帮助 ─┬─ 支持开发者 ─→ IPC app:paymentQr ─→ 主进程读「收款码」目录图片 → data URL → 弹窗 <img>
      └─ 打开官网   ─→ IPC app:openOfficialSite ─→ shell.openExternal(https://www.lcode.ai.info)
```
- 收款码图片**只由主进程读盘**（渲染层 sandbox + contextIsolation，不直接读文件、也没有任意路径读取能力）；
  单张上限 5MB、最多 6 张，转成 `data:` URL 后交给渲染层展示；
- 目录解析顺序：`LCODE_QR_DIR` 环境变量 → 仓库根 `<仓库>/收款码`（dev：`desktop/../..`）→ 打包 `resources/收款码`；
  找不到图片时弹窗给出「未找到收款码图片」+ 候选目录路径（便于排错）；
- 官网 URL **写死在主进程**（渲染层不传地址），避免 IPC 变成任意链接跳板。

**首页交互清单：**
| 元素 | 行为 |
|---|---|
| 左栏「项目」列表 | distinct 工程目录（对话会话的 cwd / 流水线任务 project_dir / 当前打开文件夹汇总去重），按最近活动降序；最多 10 条可见，超出滚轮滚动；📂 按钮 = 打开文件夹并登记为新项目 |
| 项目行点击 | 选中 → 右栏切换为该项目的全部聊天记录（同时作为当前工作区，后续新对话绑定该项目） |
| 右栏「聊天记录」胶囊 | 每个对话会话 = 一个胶囊（默认标题 = 会话首条输入，最多 50 字 + 省略号）；点击 → 跳工作区视图打开该会话；右键 → 删除（重命名暂缓） |

| 文件→打开文件夹 / 选中项目 | 进入工作区后**自动加载该项目最新一条聊天记录**（草稿按会话键回填）——2026-09 用户拍板 |
| 旧「流水线任务记录」列表 | 已按产品决策从首页移除（任务详情仍可从对话内触发/查看） |

## 4. 文件树（FileTreePane）—— 左侧栏

```
┌─────────────────────────────────────┐
│  📁 esp32_rtos                   📂 │  ← 根目录标题 + 资源管理器打开
│ ─────────────────────────────────── │
│  > 📁 main                        │  ← 点击箭头或目录名展开/收起（惰性加载）
│  > 📁 build                       │
│  > 📄 sdkconfig.defaults          │  ← 点击文件 → 中间窗打开
│  > 📄 CMakeLists.txt              │
│  > 📄 README.md                   │
│  ───────────── 展开后 ────────────  │
│  ⌄ 📁 main                        │
│     > 📄 CMakeLists.txt           │
│     > 📄 main.c                   │  ← 缩进随层级 ×14px
│                                   │
└─────────────────────────────────────┘

交互规则（契约最严格，防改坏红线）：
- 根永远显示在树顶（= 当前工作区目录），❗点击文件夹绝不改变根、不顶替整棵树
- 子文件夹"原地展开/收起"；无"上级/回退"按钮
- 惰性加载：展开才请求子项，缓存于 children[path]，收起再展开不重复请求
- **数据源 = 主进程本地 fs**（`main/workspace-fs.ts`，IPC `workspace:listFiles`）：
  不再走内核 HTTP——「打开文件夹」会重启内核（冷启动 30~60s），旧实现重启窗口内必失败，
  用户得手点 ⟳ 才看到目录（实测 bug）；本地 fs 打开文件夹即显示
- **自动刷新**：主进程 `fs.watch` 递归监听工作区根，内容变化去抖 200ms 推送
  `workspace:changed` → 文件树重载根 + 重取已展开目录（保留展开状态）；
  切换工作区（store workspaceRoot 变化）也立即重载 → 已移除「⟳ 刷新」按钮
- 失败容错：根/子目录失败内联「目录读取失败」+ 子目录「点箭头重试」（无内核重启窗口需覆盖）
- 📂 资源管理器打开工作目录（「📦 导出 zip」与「⟳ 刷新」按钮已按用户拍板移除）
```

## 6. 对话聊天框（ChatPane）—— 右侧栏 / 工作区模式

> **打开文件夹后自动续上历史会话（2026-09）**：`打开文件夹`/`选中项目` → 进工作区时自动打开该项目
> **最新一条聊天记录**，输入框按会话草稿回填；`✨新建对话` 则保持空会话（不被旧会话抢回）。
> ⚠️ 「打开文件夹」会重启内核（`--outputs` 生效，冷启动 30~60s）：重启窗口内聊天接口全部不可达，
> 因此 **`kernel:getChatSession` 必须区分 404（会话确实不存在 → 回落空会话）与其它异常
> （内核不可达 → 抛 E_KERNEL_UNREACHABLE，渲染层重试 1.5s×60≈90s）**；
> 期间消息区显示「内核启动中…（打开文件夹会重启内核…）」，就绪后历史消息与草稿一起出现。
>
> **会话标题行（聊天框上方）**：`会话标题` + 运行中徽章（仅运行时出现）+ **「＋ 新会话」按钮**
> （2026-09 用户要求：原「空闲」状态位改为「新会话」按钮）——点击立即切到空会话引导新建会话；
> 当前会话**不删除**，仍留在项目里（首页/项目列表可再次打开）；运行中点击也不会打断旧会话
> （旧会话继续在后台跑，可回首页打开）。

```
│  │ │ ✓ code_generate 生成 main.c    2.1s[▾] │ │ │
│  │ │ ⏳ build  ESP-IDF 编译          运行中…  │ │ │
│  │ └────────────────────────────────────────┘ │ │
│  │                                            │ │
│  │ 编译中… ━━━━━━━━━━━━━━━ 45%              │ │   ← 编译进度
│  └────────────────────────────────────────────┘ │
│  ┌────────────────────────────────────────────┐ │
│  │ 固件已生成，是否烧录到开发板？                  │ │   ← 会话结束 → 烧录询问
│  │                           [烧录] [取消]     │ │
│  └────────────────────────────────────────────┘ │
│  ───────────────────────────────────────────── │
│  ┌─ 待发送（2）───────────────────────────────┐ │   ← 运行中排队/已 steer 未消费
│  │ 排队  再顺手把日志等级调成 debug        ✕ │ │     （DSH QueueDock 同源；可删除）
│  │ 立即  顺便跑一次单测                    ✕ │ │
│  └────────────────────────────────────────────┘ │
│  [+ /plan][Plan ✕][high]              [↑][⏹]  │   ← 运行中：输入框可选中可输入，
│  Enter 排队 · Ctrl+Enter 立即发送                │      Enter=排队 / Ctrl+Enter=立即投递

└────────────────────────────────────────────────┘
```

> **运行中发送语义（照抄 DSH，2026-09）**：Agent 运行中输入框**不再禁用**——
> 可选中、可输入、可发送。`Enter` = **排队**（消息停在服务端 inbox，本轮结束后作为自己的一轮执行）；
> `Ctrl/Cmd+Enter` = **立即投递**（steer：注入运行中本轮最近的 step 边界被消费）；
> 待发送消息显示在输入框上方，可单条删除；发送键与红色停止键**同时存在**。
> 固定按 DSH 语义（不受设置页「发送方式」影响；空闲时仍按设置页 Enter/Ctrl+Enter 发送）。

## 9. 界面关键交互与状态汇总

| 状态/事件 | UI 呈现 |
|---|---|
| 任务状态徽章 | 排队中(黄)/执行中(蓝)/成功(绿)/失败(红)/已取消(红)/已中断(muted) |
| 内核状态 | 已停止/启动中…/运行中/已崩溃（自动重启中…） |
| 内核重启窗口 | 文件树不受影响（走主进程本地 fs，不依赖内核）；聊天区显示「内核启动中…」，历史会话自动重试加载（1.5s×60≈90s）；首页跳过刷新不刷错误 |
| 切换工程 | 切换文件夹/任务 → **中间内容窗自动关闭**上一个工程打开的 文件/产物（不再残留旧文件报“无法读取”） |
| 聊天框标题行 | 会话标题 + 运行中徽章（仅运行时） + **「＋ 新会话」按钮**（原「空闲」状态位；点击开新会话，旧会话保留） |
| 帮助菜单 | 「支持开发者」弹收款码窗口（本地「收款码」目录图片，主进程转 data URL）；「打开官网」用系统浏览器打开 `https://www.lcode.ai.info` |
| 工作区内容变化 | 主进程 `fs.watch` 递归监听 → 去抖 200ms 推 `workspace:changed` → 文件树立即刷新（保留展开状态） |
| 会话实时事件 | `onKernelEvent` 推送优先，2s轮询兜底 |
| 运行中发送 | 输入框可选中/可输入/可发送（DSH 语义）：Enter=排队、Ctrl+Enter=立即投递(steer)；发送键与停止键并存；排队消息显示在输入框上方「待发送」（可删） |
| 三栏宽度 | 分隔条可鼠标拖拽（文件树/内容窗/聊天）；宽度持久化（treeWidth/chatWidth），重启保持 |
| 输入框高度 | 随内容自动增高，上限 = 聊天面板总高度的一半，超出在框内滚动（面板尺寸变化时自动重算） |
| 文字流式 | W1 打字机尾巴 + `StreamCaret`（2px 蓝色光标位） |
| 上下文占用圆环 | 14px SVG 圆环，ok绿/warn黄/danger红 + 百分比 + 将满红色提示 |
| 草稿持久化 | 聊天输入按"工作区+会话"分键存 localStorage，切界面/重启不丢 |
