# 知识库目录（芯片手册）

把厂商手册放这里只是为了**本机建库**：本仓库不含知识库实现与向量库
（切片策略/向量库/语料在私有仓 `lcode-kb`），厂商 PDF 也不随仓库发布。

```powershell
# 装了私有知识库包之后，用它扫描本目录建库
python -m lcode_kb.load_docs --assets <本目录>
```

| 目录 | 放什么 | 是否入库（向量化） |
|---|---|---|
| `芯片手册\` | ESP32-S3 Datasheet、技术参考手册等 | ✅ 入库（核心） |
| `开发板手册\` | 开发板引脚说明、原理图文字版说明（md/txt 更佳） | ✅ 入库 |
| `外设手册\` | 传感器/外设芯片手册（如 AHT20、SHT30 datasheet） | ✅ 入库 |
| `原理图\` | 图形版原理图（.sch/.kicad_sch/图形 PDF） | ❌ **自动跳过**（在建库脚本的排除目录名单里，图形内容无法检索） |

## 支持格式

`.pdf` / `.md` / `.txt`（递归扫描）。

## 芯片标签

文件名或所在目录名含 `esp32s3` / `esp32-s3` / `esp32` 的文档会自动打上 `chip=esp32s3` 标签，检索时按芯片过滤。

## 提示

- 优先放：ESP32-S3 Datasheet（必放）+ 开发板引脚说明（md/txt 最佳）+ 温湿度传感器 datasheet
- 图形 PDF 原理图放在 `原理图\` 即可，不会被检索
- 切换 embedding 模型后需删除向量库目录再重建
- 没装私有知识库包时，内核走**通用模式**（检索返回空，界面「手册检索」置灰），本目录不会被读取
